Messaging Attachment Test Harness

This page tests the WAITING chat status file attachment error using an unauthenticated token payload.

Reproduction Steps:
  1. Ensure Omni-Channel agent status is set to Offline in Salesforce.
  2. Click the chat launcher icon below to start a session (status: WAITING).
  3. Click the paperclip icon inside the chat widget.
  4. Upload a 4.5MB – 5MB PDF file and click Send.
