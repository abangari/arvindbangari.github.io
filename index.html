Salesforce Custom Client Embedded Messaging Test Harness

This interactive environment hosts the Salesforce Custom Client (MIAW) chat widget. It is designed to simulate end-user PDF attachment uploads while a session is queued in WAITING status to trigger the synchronous Apex heap size limit exception.

Reproduction Protocol

Follow steps strictly to capture Apex Exception Log
01

Set Omni Agent Offline

In Salesforce Service Console, ensure your user's Omni-Channel status is set to Offline so incoming chats are queued.

02

Initiate Chat Session

Click the chat widget on this page to start a chat session. Confirm the session status displays as WAITING.

03

Attach ~4.8 MB PDF File

Click the attachment paperclip icon in the chat widget and select a PDF file between 4.5 MB and 5.0 MB.

04

Observe LimitException

Submit the file. The upload will fail in the chat UI, and an unhandled System.LimitException will generate in Apex Logs.

CORS Authorization Checklist

Salesforce Embedded Messaging enforces Cross-Origin Resource Sharing (CORS). Ensure your active domain is added to Salesforce setup, otherwise network requests will fail silently.

Origin Pattern: https://arvindbangari.github.io
Root Cause Summary

Synchronous ContentVersion AfterInsert trigger (SkyhighNetworks.SHNContentVersionEvents) serializes raw binary into Base64/JSON, exceeding the 6MB heap limit.

Salesforce Apex Limit: 6 MB Synchronous Heap
